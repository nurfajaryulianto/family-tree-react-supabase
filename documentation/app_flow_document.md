# App Flow Document for Family Tree React Supabase Application

## Onboarding and Sign-In/Sign-Up

A brand-new user lands on a simple, informative landing page that highlights the family tree app’s core features: interactive genealogy builder, photo studio, GEDCOM import/export, DNA integration, and collaborative tools. The page offers clear buttons for signing up and logging in. When the user clicks Sign Up, they are taken to a registration page where they can create an account by entering their name, email address, and password. Alternatively, the user may choose social login buttons such as Google or Apple, which open a pop-up to complete authentication before returning them to the app. After successfully registering, the app sends a confirmation email; once the user clicks the confirmation link, they are automatically signed in and guided to create their first family tree or explore a demo tree. If a returning user clicks Log In, they enter their email and password or select a social login option and are authenticated immediately. A link below the form leads to the Forgot Password page, where the user types their email address to receive a password reset link. Clicking that link opens a secure page for entering and confirming a new password. Two-factor authentication can be enabled from the Settings page later, but once activated, sign-in requires an additional code sent via SMS or generated by an authenticator app. A Sign Out button is always visible in the header, and clicking it immediately ends the session and returns the user to the landing page.

## Main Dashboard or Home Page

Upon signing in, the user lands on the Main Dashboard. At the top is a header bar displaying the app logo, a search field, a notifications icon, and the user’s avatar with a dropdown for account actions. On the left side is a collapsible sidebar providing navigation links to Dashboard, Family Tree, Members, Photo Studio, GEDCOM, DNA, Settings, and Help. The center of the page shows dashboard widgets: Recent Activity feed listing the latest tree edits and collaboration invites, a New Discoveries panel suggesting new relationships, and Upcoming Events highlighting birthdays and anniversaries. Each widget has a View More link at the bottom to navigate to its full page. A prominent button labeled View My Tree takes users directly into their Visual Tree Builder. From the dashboard, the user can navigate to any other section by clicking the corresponding sidebar item or the main header menu.

## Detailed Feature Flows and Page Transitions

When the user clicks View My Tree or selects Family Tree from the sidebar, they enter the Visual Tree Builder page. This full-screen canvas displays a zoomable and pannable representation of the tree. Each person appears as a node with their name and portrait. Hovering over a node highlights it, and clicking a node opens a Radial Menu around it with options to Add Relative, Edit Profile, or Remove Member. Choosing Add Relative launches a modal dialog containing a form with fields for name, birthdate, and relationship type. The form validates entries in real time, and on submission, the new person and relationship are added to the Supabase database. Thanks to real-time subscriptions, the new node appears instantly on the canvas. When the user clicks Edit Profile on the Radial Menu, they transition to a Member Profile page that displays detailed information: personal info, event dates, family links, photos, and documents. On this page, the user can click Edit to modify fields in a form and save changes.

Clicking the Members link in the sidebar navigates to a searchable list of all relatives. Typing into the search bar filters members by name or date. Selecting a member redirects to the same Member Profile page described above. From any profile, a Back to Tree button returns the user to the exact spot on the Visual Tree Builder.

The Photo Studio page is accessible via the sidebar. On arrival, the user sees options for Upload Photo, Colorize, Restore, and Animate. Clicking Upload Photo opens a file picker; after choosing an image, the file appears in a preview pane. Selecting an enhancement mode like Colorize sends the image to a Supabase Edge Function running the AI model. A loading indicator shows progress, then the enhanced image replaces the preview. The user can download it or attach it directly to a member profile using a dropdown list of family members.

When the user selects GEDCOM from the sidebar, they land on the GEDCOM Import/Export page. To import, the user clicks Import, picks a .ged file, and the app calls an Edge Function to parse and map GEDCOM data into the database. A progress bar updates during parsing, and when complete, the tree updates in the Visual Tree Builder. To export, the user clicks Export, which triggers a function that compiles the current tree into a GEDCOM file and presents a download link once ready.

Clicking DNA opens the DNA Data Integration page. Here, the user accesses Upload Raw Data to submit a file from a third-party DNA service. The file is sent to a Supabase Edge Function for processing. Upon completion, the user receives an ethnicity report and a list of potential relatives. Clicking View on any suggested relative opens that member’s profile or invites the user to add them to the tree.

Collaboration flows are woven throughout. From any page, the user may click Invite at the top of the sidebar, which opens a dialog to generate a secure link or QR code. The recipient clicks the link, creates an account if needed, and gains view-only or edit rights based on the invitation settings. Real-time updates ensure everyone sees changes instantly.

Premium features such as Automatic Matching and advanced AI options are marked with a lock icon. Clicking a locked feature opens a subscription prompt. If the user chooses to subscribe, they are taken to the Billing page under Settings.

## Settings and Account Management

Selecting Settings in the sidebar leads to the Account Settings section, which loads separate tabs for Profile, Security, Notifications, and Billing. On the Profile tab, the user can update their name, email, and avatar. In Security, they can change their password, enable Two-Factor Authentication, and view active sessions with a Sign Out of All Sessions button. Notifications lets the user toggle email or in-app alerts for events like collaboration changes, anniversaries, or GEDCOM import completion. The Billing tab displays the current subscription plan and payment method. If the user has no active subscription, a Subscribe button opens a Stripe-powered payment form to enter credit card details and select a plan. After updating any setting, a Save button confirms changes and shows a brief success message. From any tab, a Back to Dashboard link returns the user to the Main Dashboard.

## Error States and Alternate Paths

If the user enters invalid data in any form, inline error messages appear next to the affected fields explaining the issue in plain language. Failing to upload a supported file type for photos, GEDCOM, or DNA displays an alert at the top of the page outlining acceptable formats. If the network connection drops during a save or upload, a persistent banner appears at the top of the screen notifying the user of offline mode and auto-retry behavior. Any failed call to the server displays a retry button, allowing the user to attempt the action again. Unauthorized access attempts—for example, clicking a subscription-only feature without an active plan—trigger a modal explaining that the feature is reserved for premium users and offering a link to the Billing page.

## Conclusion and Overall App Journey

From the first moment a user signs up, they are guided into a welcoming landing page, through secure authentication, and into a dynamic dashboard that highlights tree building, collaboration, and discovery. As they explore the Visual Tree Builder, they add and edit relatives with intuitive modals and context menus. They manage detailed Member Profiles, enhance family photos with AI, import and export GEDCOM files, and analyze DNA data—all within a cohesive navigation structure. Settings let them customize their profile, security, notifications, and billing preferences, while graceful error handling keeps them informed and in control. Ultimately, every step in this app is connected, providing a smooth, end-to-end experience from creating a family tree to enriching it with advanced genealogical tools and sharing it with loved ones.
